1. Derivation of Knuth's Recurrence Formula for the Mean

Let $\bar{x}_k = \frac{1}{k} \sum_{i=1}^k x_i$ be the sample mean of the first $k$ scores. Isolating the newest observation $x_k$:

$$\bar{x}_k = \frac{1}{k} \left( \sum_{i=1}^{k-1} x_i + x_k \right) = \frac{1}{k} \left( (k-1)\bar{x}_{k-1} + x_k \right)$$ $$\bar{x}_k = \frac{k\bar{x}_{k-1} - \bar{x}_{k-1} + x_k}{k} = \bar{x}_{k-1} + \frac{x_k - \bar{x}_{k-1}}{k}$$

Defining the prior-mean error $\delta_k = x_k - \bar{x}_{k-1}$, we obtain Knuth's exact streaming recurrence: $$\bar{x}_k = \bar{x}_{k-1} + \frac{\delta_k}{k}$$

2. Rigorous Algebraic Derivation of Welford's Sum of Squares ($M_{2,k}$)

Define $M_{2,k} = \sum_{i=1}^k (x_i - \bar{x}_k)^2$. Separating the summation over the prior $k-1$ elements from the new score $x_k$:

$$M_{2,k} = \sum_{i=1}^{k-1} (x_i - \bar{x}_k)^2 + (x_k - \bar{x}_k)^2$$

Write $x_i - \bar{x}_k = (x_i - \bar{x}_{k-1}) + (\bar{x}_{k-1} - \bar{x}_k)$ and expand the squared binomial over $i=1 \dots k-1$:

$$\sum_{i=1}^{k-1} (x_i - \bar{x}_k)^2 = \sum_{i=1}^{k-1} (x_i - \bar{x}_{k-1})^2 + 2(\bar{x}_{k-1} - \bar{x}_k) \underbrace{\sum_{i=1}^{k-1}(x_i - \bar{x}_{k-1})}_{= 0 \text{ identically}} + (k-1)(\bar{x}_{k-1} - \bar{x}_k)^2$$ $$M_{2,k} = M_{2,k-1} + (k-1)(\bar{x}_{k-1} - \bar{x}_k)^2 + (x_k - \bar{x}_k)^2$$

Using Knuth's relationship $\bar{x}_{k-1} - \bar{x}_k = -\frac{x_k - \bar{x}_{k-1}}{k} = -\frac{\delta_k}{k}$ and $x_k - \bar{x}_k = \delta_k \left(1 - \frac{1}{k}\right) = \delta_k \frac{k-1}{k}$:

$$(k-1)\left(-\frac{\delta_k}{k}\right)^2 + \left(\delta_k \frac{k-1}{k}\right)^2 = \delta_k^2 \frac{k-1}{k^2} (1 + k - 1) = \delta_k^2 \frac{k-1}{k} = \delta_k (x_k - \bar{x}_k)$$ $$M_{2,k} = M_{2,k-1} + \delta_k (x_k - \bar{x}_k)$$

Bessel's unbiased sample variance for any sample size $k \ge 2$ is: $$s_k^2 = \frac{M_{2,k}}{k - 1}$$ Statistical Singularity at $k=1$: For a single sample, $s_1^2 = \frac{0}{1-1} = \frac{0}{0} = \mathrm{NaN}$. A single sample carries zero degrees of freedom; setting it to zero is statistically invalid as it would deceptively suggest zero variability.
