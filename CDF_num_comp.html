Mathematical Foundations & Non-Elementary Antiderivatives

Liouville's Theorem on Elementary Integrals

Can the antiderivative $\int e^{-t^2/2} \, dt$ be expressed in finite terms using elementary operations (polynomials, exponentials, logarithms, roots, trigonometric functions)?

Theorem (Joseph Liouville, 1835): If $f(t)$ and $g(t)$ are rational functions with $g(t)$ non-constant, the integral $\int f(t) e^{g(t)} \, dt$ is elementary if and only if there exists a rational function $w(t)$ satisfying:

$$w'(t) + w(t) g'(t) = f(t)$$

For $e^{-t^2/2}$, we set $g'(t) = -t$ and $f(t) = 1$, yielding:

$$w'(t) - t \, w(t) = 1$$

Expressing $w(t) = \frac{P(t)}{Q(t)}$ as a quotient of coprime polynomials and comparing asymptotic degrees at infinity immediately generates a contradiction. Consequently, $\Phi(x)$ cannot be expressed in terms of elementary functions.

Analytical Representation via $\operatorname{erf}(z)$

Because no elementary closed form exists, the error function is defined as a canonical special function:

$$\operatorname{erf}(z) = \frac{2}{\sqrt{\pi}} \int_0^z e^{-t^2} \, dt$$

Substituting $t = u / \sqrt{2}$ connects the cumulative distribution analytically:

$$\Phi(x) = \frac{1}{2} \left[ 1 + \operatorname{erf}\left( \frac{x}{\sqrt{2}} \right) \right]$$

Why numerical methods remain necessary: Assigning a name to a non-elementary integral formalizes the mathematics, but modern CPUs have no direct physical circuits for evaluating transcendental functions without approximation algorithms.

High-Precision Identity via Regularized Incomplete Gamma $Q(a, z)$

The standard normal CDF can be rigorously expressed through the upper regularized incomplete gamma function $Q(a, z) = \frac{\Gamma(a, z)}{\Gamma(a)}$:

$$\Phi(x) = \begin{cases} \frac{1}{2} Q\left(\frac{1}{2}, \frac{x^2}{2}\right), & x < 0 \\[6pt] 1 - \frac{1}{2} Q\left(\frac{1}{2}, \frac{x^2}{2}\right), & x \ge 0 \end{cases}$$

This provides an independent mathematical reference capable of reaching double-precision accuracy ($\approx 10^{-15}$) via continued fraction expansion.

Comparison of Numerical Schemes

  • Numerical Quadrature (Trapezoidal, Simpson): Approximates $\Phi(x) \approx \int_{A}^x \phi(t) \, dt$ with a cut-off limit $A = -8.0$. While clear and intuitive, high accuracy requires computing hundreds of costly transcendental exponential evaluations $\exp(-t^2/2)$.
  • Maclaurin Taylor Series: Expanding $\operatorname{erf}(z)$ yields the series $\frac{2}{\sqrt{\pi}} \sum_{k=0}^{\infty} \frac{(-1)^k z^{2k+1}}{k!(2k+1)}$. Although analytically convergent for all $z \in \mathbb{R}$, evaluating it for $|x| > 2.5$ causes severe catastrophic subtraction errors in floating-point arithmetic.
  • Rational Approximations (A&S 7.1.26): Evaluates a rational polynomial ratio $P(t) / Q(t)$ in the auxiliary variable $t = (1 + p |x|)^{-1}$. It requires only a single $\exp(-x^2/2)$ call and provides an error bounded by $|\epsilon(x)| \le 7.5 \times 10^{-8}$.
